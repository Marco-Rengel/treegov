# Referencia Visual: Estándar Clásico de Estaciones de Árboles (circa 2001)

## 1. Barra de Herramientas (Toolbar)
- Debe ser extremadamente compacta (altura máxima 30px).
- Solo iconos, SIN texto (ToolButtonIconOnly).
- Iconos pequeños (16x16 o 24x24) con tooltips al pasar el ratón.
- Agrupación de iconos: [Archivo] | [Vistas/Tablas] | [Zoom] | [Edición].

## 2. Layout Principal
- **Panel Izquierdo (Vertical):** 
  - Arriba: Project Explorer (lista de modelos).
  - Medio: Tree Map (minimapa del árbol con nodo actual resaltado).
  - Abajo: Data Viewer (tabla con los datos del dataset).
- **Panel Central:** 
  - Canvas del árbol (ocupa el 100% del espacio en su pestaña).
  - Pestañas inferiores: `Tree`, `Gains`, `Risks`, `Rules`, `Summary`.
- **Panel Derecho:** Propiedades / Gobernanza (acotado a un ancho máximo de 400px).

## 3. Estructura Visual de los Nodos
Cada nodo debe renderizarse como una tarjeta HTML con:
- **Cabecera:** Bloque de color sólido con el nombre de la variable (azul para internos, verde/rojo/naranja para hojas). Texto blanco.
- **Tabla Interna:** Cabecera `Category | % | n`. Una fila por clase (con un pequeño cuadrado de color a la izquierda del nombre de la clase).
- **Fila Total:** `Total (pct_global) n_total` separada por una línea superior.
- **Gráfico de Barras:** Justo debajo de la tabla, un gráfico de barras apiladas o proporcional por clase.
- **Metadatos (Footer):** En texto gris pequeño: `Adj. P-value`, `Chi-square`, `df` (para internos), o `Gini` (para hojas).
- **Espaciado:** Sin márgenes internos excesivos. El nodo debe ajustarse al contenido.

## 4. Interactividad del Tree Map
- Al hacer clic en un nodo del minimapa, el Canvas principal hace `panning` (se desplaza para centrar el nodo) **manteniendo el nivel de zoom actual**. No hace zoom fit automático.

## 5. Menú Contextual del Nodo (Clic Derecho)
- Opciones: `Grow Tree`, `Grow Tree One Level`, `Select Predictor`, `Define Split`, `Remove Branch`, `Prune Branch`.
- Esta funcionalidad se implementará en la Fase 3.11.d.
