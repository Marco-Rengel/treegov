# TreeGov — Fase 3.10.b: Hotfix Visual y Alineación CHAID

**Purpose.** Este documento define el diseño formal para cerrar los hallazgos visuales pendientes de la Fase 3.10.a y la alineación del motor CHAID con predictores continuos.

**Status.** Propuesto. Pendiente de auditoría de diseño previa a la implementación.

## §0. Alcance

1. **Hotfix Visual (H9, H11, H12, H13):** Correcciones de UI pendientes de la Fase 3.10.a.
2. **Alineación CHAID (H14):** Implementación de binning automático para predictores continuos.

## §1. Hotfix Visual (Frontend)

- **H9 (Wizard):** Añadir regla QSS `QDialog, QWizard { background: $BG; }` en `styles.qss`.
- **H11 (Barras):** Añadir reglas específicas para `QMenuBar::item` y `QToolBar QToolButton` para evitar el fondo negro del sistema.
- **H12 (Zoom):** Corregir `TreeView.zoom_fit()` en `tree_view.py` para que el factor de escala calculado por `fitInView` respete el límite inferior `ZOOM_MIN`.
- **H13 (Nodos):** Reescribir `_node_label` en `tree_view.py` para usar HTML con fondo transparente (`background: transparent`), cabecera de color, tabla interna (`Categoría | % | n`), barra fina y footer (`Gini`, `p-valor`, `n`). No se añade KS por nodo en esta fase.

## §2. Alineación CHAID Continuas (Backend)

- **Objetivo:** Permitir variables `[CONT]` en los motores CHAID y CHAID_EXHAUSTIVE (actualmente rechazadas por contrato).
- **Método:** Binning por cuantiles (deciles por defecto).
- **Impacto en `SplitConfig`:** Se añade el campo `bin_edges: tuple[float, ...] = ()` para almacenar los cortes de los bins.
- **Impacto en `TreeBuilder._partition`:** Si `cfg.bin_edges` no está vacío, el enrutamiento se hace por rangos numéricos (`np.digitize`) en lugar de por pertenencia a categorías.
- **Gobernanza:** El binning se calcula en el nodo usando los pesos si la sesión es ponderada. El fingerprint cambiará para reflejar esta nueva lógica.

## §3. Invariantes

- K=2 debe seguir siendo numéricamente idéntico si no se usan continuas en CHAID.
- La suite de 438 tests debe pasar (con adaptaciones en `test_chaid_engine.py` y `test_uci_integration.py`).
