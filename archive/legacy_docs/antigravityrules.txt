[UI_UX_STANDARDS]
# Directrices de Diseño y Experiencia de Usuario en PySide6:
# 1. Prohibición del Anti-Patrón BI:
#    - NO transformar la aplicación en un dashboard o grilla densa de tablas editables interactuando entre sí.
#    - Preservar la estética institucional, sobria y de alta fidelidad estadística (estilo Stata / SPSS / SAS).
# 2. Paradigma de Lienzo Central (Workspace-Centric):
#    - El área de trabajo central (`centralWidget`) es un QSplitter permanente con el Lienzo del Árbol (70%)
#      y el panel de Cortes Candidatos Asistidos (30%).
#    - NO reintroducir QTabWidget como contenedor de nivel superior en la ventana principal.
# 3. Output Viewer Estadístico Desacoplado:
#    - Los reportes analíticos (Resumen del Modelo, Tabla de Ganancias, Matriz de Clasificación,
#      Panel de Validación OOS/OOT, Monitor de Estabilidad PSI/CSI, Bitácora de Intervenciones)
#      deben implementarse dentro de `ReportWindow` flotantes/acoplables.
#    - El renderizado de métricas y tablas debe emplear `QTextBrowser` con marcado HTML/CSS minimalista,
#      garantizando copia limpia en formato TSV y exportación directa a CSV.
# 4. HUD Lateral Compacto:
#    - El panel lateral acoplable (`PropertiesPanel`) debe mantenerse como un visor compacto (HUD)
#      restringido exclusivamente a métricas clave del nodo activo y botones de acción, envuelto
#      en un `QScrollArea` elástico con `widgetResizable=True` y sin bordes.
# 5. Modularidad Regulatoria:
#    - La gobernanza MRM / IFRS 9 (Bitácora, Corte Asimétrico, Alertas de Auditoría) debe estar gobernada
#      por el conmutador global ("Habilitar Modo MRM / IFRS 9").
